## 本文

株式会社ウォーカー（本社：東京都文京区、代表取締役：伊東雄歩）と株式会社sunUが共同運営する3Dプリンタ教室・体験スタジオ「3DLab」は、2026年7月24日より、継続学習コース「3DLabスクール」の新規入会者を対象に「入会金無料キャンペーン」を開始しました。通常22,000円（税込）の入会金が0円になります。既存特典である「入会月の月謝無料」と併用でき、合計39,000円分の初期費用なしで通いはじめられます。対象は2026年9月30日までのお申し込み分です。

申込：https://3dlab.jp/school

### ■ 背景 ―― 体験して終わりにしない場所をつくる

3DLab はこれまで、単発の体験ワークショップを軸に運営してきました。参加者が2時間でひとつ作品を仕上げて持ち帰る、その体験自体は成立しています。

一方で、終了後に「次はこれを作ってみたい」と話し出す子どもが少なくありません。ところが、その続きをやる場所がない。家に3Dプリンターはなく、モデリング環境もない。せっかく生まれた「作りたい」が、その日で途切れてしまいます。

継続学習コース「3DLabスクール」は、この続きを引き受けるために用意したものです。ただし、継続コースには入会金という最初のハードルがあります。「子どもが続けられるか分からないうちに、入会金と初月の月謝をまとめて払うのは判断が難しい」という声を、実際に体験会の現場でいただいてきました。

今回のキャンペーンは、金額を理由に検討をやめてしまう状態をなくすことを目的としています。

### ■ キャンペーン概要

| 項目 | 内容 |
| --- | --- |
| 名称 | 3DLabスクール 入会金無料キャンペーン |

| 特典 | 入会金 22,000円（税込）→ 0円 |

### ■ 「自由創作クラス」について

| 項目 | 内容 |
| --- | --- |
| 月謝 | 17,000円（税込）/月 |
| 回数 | 月2回（開校日の中からご都合の良い日を選択） |
| 時間 | 120分/回 |
| 対象 | 5歳〜18歳 |

決まったカリキュラムを一斉に進める形式ではありません。一人ひとりが自分の「作りたいもの」に取り組み、詰まった時にその場で講師へ質問できる環境です。PCと有料版AIを教室で自由に使えるため、家庭側で機材やツールを用意する必要はありません。

体験ワークショップで採用しているクリエイター向けプラットフォーム「miraipage」の制作環境も、スクールへ順次展開していく予定です。

## 3DLab について

3DLab（ https://3dlab.jp ）は、東京都文京区湯島（東京メトロ千代田線 湯島駅 徒歩1分）にある3Dプリンタ教室・体験スタジオです。子ども・大人向けの体験ワークショップ、継続学習コース、3Dプリント/試作の受託、企業研修・オフサイトイベントなどを提供しています。株式会社sunU・株式会社ウォーカーの共同運営。

なお3DLabの取り組みは、3Dプリンター専門メディア「ShareLab NEWS（シェアラボ）」やYouTubeチャンネル「AI・ネクストニッポン【公式】」でも紹介されています。
