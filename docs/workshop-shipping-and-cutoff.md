# オンラインワークショップの発送先と予約締切

## 本番反映

1. `supabase/migrations/20261004000000_workshop_shipping_and_cutoff.sql` をデータベースに適用する。
2. アプリを公開する。SQL適用を先に行う（新しい列をフォームとAPIが参照するため）。
3. ワークショップ編集画面で対象イベントの「国内発送先住所を必須にする」と「予約受付を開催日の何日前に終了するか」を確認する。

SQLはタイトルまたは開催場所に「オンライン」と明記された既存ワークショップの住所必須を有効にし、締切を5日前に設定する。表記が異なるオンライン開催は管理画面で設定する。既存予約には住所の入力を要求せず、保存済みの予約を変更しない。

## 設定と動作

新規作成・編集画面で住所必須を有効にすると、締切日数の初期値が5になる。住所は予約ごとに郵便番号・47都道府県の選択・市区町村以降の住所を保存し、予約管理画面に表示する。宛名は予約者のお名前を使用する。

締切日数5の場合、10月10日開催の予約受付は10月5日午前0時（日本時間）で終了する。人数に関係なく仮予約作成API・DBの予約保存・有料決済開始・無料予約確定で締切を検証する。既存の予約0人の場合の締切と併用し、早い締切を適用する。締切日数0は締切なし。開催回が複数ある場合は選択した開催日の締切を使う。

締切前に開始したStripe決済の完了は、既存の決済有効期限内で受け付ける。新規予約保存時のDBトリガーは既存予約の更新には適用しない。
