## 本文

3Dプリンタ教室・体験スタジオ **「3DLab」**（株式会社sunU・株式会社ウォーカー 共同運営／東京都文京区湯島）は、**2026年9月3日、オリジナルのクッキー型を作れるWebツール「クッキー型メーカー」を公開しました。**

お子さんが描いた絵、お店のロゴ、名前の文字――そうしたものをブラウザにアップロードするか入力するだけで、3Dプリンターで印刷できるクッキー型の立体データができます。**3Dの知識も、専用ソフトも要りません。** 作る作業自体は無料で、気に入ったデータだけを買えます。

公開URL：https://3dlab.jp/cookie-cutter

### 4つの入口から、同じように型になる

型のもとにできるものを4つ用意しました。どれを選んでも、同じ手順で立体になります。

| 入口 | できること |
| --- | --- |
| きほんの形 | 丸・四角・三角・五角形・六角形・星・ハートなど15種から選ぶ |
| 絵・写真 | 手描きの絵やロゴの画像を読み込む。SVGにも対応 |
| 文字 | 名前などを入力する。太さの違う書体を6種から選べる |
| アイコン | 動物・食べもの・行事など、122種のアイコンから選ぶ |

**お子さんが描いた絵をそのまま型にできます。** 白い紙に濃いペンで描いたものが一番きれいに出ますが、線が途切れていたり、輪郭がギザギザだったりする場合も、画面のつまみで整えられます。

名前を入力すると、**1文字ずつが刃になり、平らなふちで1枚につながった型**ができます。市販の名前入りクッキー型と同じ作りです。

### 「印刷できない形は売らない」という考え方

このツールでいちばん手をかけたのは、**作った型が本当に使えるかを機械で確かめる部分**です。

3Dのデータは、見た目が正しくても印刷できないことがあります。立体として閉じていないデータを3Dプリンターに送ると、ソフトが穴を勝手に塞ごうとして、注文とは違う形が出てきます。クッキー型では特に、**細すぎる部分は刃と刃がくっついてしまい、生地が抜けません。**

3DLabのクッキー型メーカーは、購入の前に次のことを自動で調べます。

1. **立体として閉じているか。** 閉じていない形は、そもそも購入できないようにしています
2. **生地が抜けない細い箇所がないか。** 見つかった場所を画面に赤い点で示し、どう直せばよいかを言葉で伝えます
3. **形が離れすぎていないか。** 文字などで型がバラバラの部品になる場合は、つなげ方を案内します

**買ってから「印刷できませんでした」が起きないようにする**ための仕組みです。データは決済が済んでから作るため、購入した形と届くデータが食い違うこともありません。

### その場で立体を回して確かめられる

形を決めると、**画面の右側にすぐ3Dの型が出ます。** ドラッグで回して、ホイールで拡大して、焼く前に形を確かめられます。刃の厚み・高さ、ふちの幅・厚み、クッキーの大きさは、つまみで自由に変えられます。

外形の寸法と、必要な材料の量（グラム）もその場で表示します。

### 価格

| 受け取り方 | 価格 |
| --- | --- |
| データ（STLファイル） | **300円** |
| 印刷して発送 | **3,000円**（送料込み） |

**作る作業と3Dプレビューは無料です。** ご自身で3Dプリンターをお持ちの方はデータだけを、お持ちでない方は印刷したものをお送りします。

データはSTL形式で、一般的なスライサーソフト（PrusaSlicer、Cura、Bambu Studio など）で開けます。**ふちを下にして置けばサポート材なしで印刷できる向き**で書き出しています。

### あわせて、毎日1問のアンケートを開始

**2026年9月1日から、3Dプリンターとものづくりについて、毎日1問のアンケートを始めました。**

公開URL：https://3dlab.jp/survey

「3Dプリンターは買いますか、教室で使いますか？」のような、**2つのうちどちらかを選ぶだけ**の質問です。答えると、その場でみんなの回答の割合が見られます。通知を許可すると、**翌日にその日の集計結果が届きます。**

過去の質問と結果は、すべてサイト上で公開しています。

### 背景 ―― 「教室に来る前」の距離を縮める

3Dプリンターへの関心は広がっていますが、**「気になっているが、まだ自分ごとになっていない」段階の人が多い**というのが、教室を運営してきた実感です。ワークショップに申し込むのは、その先の一歩です。

クッキー型メーカーは、**その一歩の手前に置く体験**として作りました。3Dプリンターを持っていなくても、教室に来なくても、「自分の描いた絵が立体になる」ところまでは無料で試せます。焼き上がったクッキーは、3Dプリンターでできることを、いちばん分かりやすく伝えてくれます。

毎日のアンケートも、同じ考え方です。**教室の外にいる人が何を気にしているのかを、こちらから聞きに行く。** 買うか借りるか、予算はいくらか、何を作りたいか。集まった答えは、これからの講座づくりに使います。

### 使い方（3ステップ）

1. https://3dlab.jp/cookie-cutter を開く
2. 形を選ぶ（きほんの形／絵をアップロード／名前を入力／アイコンを選ぶ）
3. 大きさを決めて、データを買うか、印刷して送ってもらうかを選ぶ

会員登録は不要です。登録すると、購入したデータを後からもう一度ダウンロードできます。

### ご利用にあたって

3Dプリントした造形物は、積層のすき間に汚れが残りやすい性質があります。**食品にお使いになる場合の衛生管理は、お客様のご判断でお願いしています。** 生地に触れる時間を短くし、使用後はよく洗って乾かしてください。食器洗い乾燥機や熱湯は変形の原因になります。

アップロードいただいた画像は、データの生成とご注文の履行にのみ使用し、お客様の許諾なく公開・第三者提供することはありません。
