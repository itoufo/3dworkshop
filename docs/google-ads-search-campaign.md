# 3DLab 検索広告（Search）セットアップ一式 — PMax以外

> Google広告の管理画面に**そのまま貼り付け／入力**すれば動く設計。
> PMaxはKW非開示で最適化不能なので、検索語が見える Search を主軸にする。
> 見出しは全角15文字・説明は全角45文字以内で作成。管理画面で赤字が出た項目だけ微調整を。

---

## 1. キャンペーン設定

| 項目 | 値 |
|---|---|
| キャンペーンタイプ | **検索（Search）** ※目標「見込み顧客の発掘」or「目標未設定で作成」 |
| ネットワーク | **検索のみ**（ディスプレイ拡張=OFF、検索パートナー=任意でOFF推奨） |
| 地域 | **東京都**（＋通える範囲。湯島から半径15〜20kmの指定でも可） |
| 言語 | 日本語 |
| 1日予算 | **¥1,500〜**（月約4.5万）。まず検索語を集める |
| 入札 | 開始は **クリック数の最大化（上限CPC ¥100目安）**。purchase CV が月15件以上安定したら **コンバージョン数の最大化 → 目標CPA ¥3,000** に切替 |
| 広告のローテーション | 最適化（既定） |
| 広告スケジュール | 終日（Web予約は24hのため）。夜間の反応を見て調整 |
| コンバージョン | 目標に **purchase（GA4インポート）** を選択（設定済みのはず） |

## 6. 立ち上げ後の運用（週1）

1. **検索語レポート**を見て、無関係な語を除外に追加（`docs/google-ads-negative-keywords.txt` に追記）。
2. 反応の良いキーワード/アドグループへ予算を寄せる。
3. `npm run ads:report -- --days 7` で コスト/クリック/CV/CPA を観測。
4. purchase CV が月15件以上で安定 → 入札を「**コンバージョン数の最大化 / 目標CPA ¥3,000**」へ切替。
5. デスクトップの成約を必ず1度実機確認（前回0成約）。
