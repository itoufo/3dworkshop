## 本文（HTML）

`blog_posts.content` は HTML で保存され、記事ページは Tailwind の `prose` 配下で描画される。
以下をそのまま貼る。

```html
<p>3DLab は、ブラウザだけで 3D プリントの準備が終わるスライサー「3DLab Slicer」を無料で公開しました。STL ファイルを入れて<strong>大きさを確認するだけ</strong>で、造形する向き・プレートへの並べ方・サポートの付け方まで自動で決まります。インストールは不要で、ブラウザで開いてすぐ使えます。</p>

<h2>なぜ作ったのか</h2>

<p>3D プリントで最初につまずくのは、モデリングではなくスライサーの設定です。教室でも受託でも、同じ質問を繰り返し受けてきました。</p>

<ul>
  <li>この向きで造形していいのか</li>
  <li>サポートはどこに、どれくらい付ければいいのか</li>
  <li>そもそも設定項目が多すぎて、どれを触ればいいのか分からない</li>
</ul>

<p>どれも「慣れれば分かる」もので、慣れるまでに失敗した造形物と時間と材料が積み上がります。既存のスライサーは高機能ですが、その高機能さがそのまま初学者の壁になっていました。</p>

<p>そこで、<strong>人が判断する項目を1つだけに絞ったスライサー</strong>を自分たちで作りました。</p>

<h2>使い方は3ステップです</h2>

<h3>1. STL を置く</h3>
<p>ブラウザのウィンドウにドラッグ&amp;ドロップするだけです。</p>

<h3>2. 大きさを確認する</h3>
<p>ここだけは人が見ます。STL というファイル形式は<strong>単位を持っていません</strong>。書き出したソフトがミリのつもりだったのか、センチやインチのつもりだったのかがファイルに書かれていないため、機械が正しく決められない唯一の項目です。</p>
<p>画面には現在の幅・奥行き・高さと、造形できる範囲が並びます。「一番長いところを 80mm にする」のような指定で直せます。桁がずれていそうなときは「10 倍では？」「inch → mm では？」と提案が出ます。ただし<strong>自動では直しません</strong>。3mm の部品を勝手に 30mm にしてしまわないためです。</p>

<h3>3. あとは自動</h3>
<p>ボタンを1つ押すと、向き・配置・サポート・ラフトまで決まって、プリントファイルができます。気に入らなければ元に戻す操作1回で、押す前の状態に戻ります。</p>

<h2>自動で決めている中身</h2>

<p>「なんとなく」で決めているわけではありません。</p>

<h3>向き</h3>
<p>大きな平面の向きと 6 軸方向から候補を作り、それぞれを傾けた変種も含めて<strong>総当りで採点</strong>します。採点している項目は次の4つです。</p>

<ul>
  <li><strong>断面積の最大値</strong> — 光造形の失敗の主因である剥離力に直結します。いちばん重く見ています</li>
  <li><strong>ほぼ水平な下向き面の広さ</strong> — 吸着と、大きな接触痕の原因になります</li>
  <li><strong>サポートが要る面の広さ</strong> — 跡の多さです</li>
  <li><strong>高さ</strong> — 層数、つまり造形時間です</li>
</ul>

<p>高さの重みは意図的に軽くしてあります。ここを重くすると、フィギュアのような縦長のものを寝かせる向きが選ばれます。造形は速く終わりますが、下面全体をサポートで支えることになり、失敗しやすくなるためです。<strong>速く終わる向きより、失敗しにくい向きを選びます。</strong></p>

<h3>サポート</h3>
<p>層ごとに断面を見て、支えが必要な島を見つけ、支える力が足りない分だけ支柱の本数を割り出して配置しています。方式は、オープンソースのスライサー PrusaSlicer の光造形向け実装を仕様として参照しました。</p>
<p>ただし<strong>支持点の密度は参照元の2倍</strong>にしてあります。1本あたりが受け持つ力が半分になり、本数が増えます。跡は増えますが、初めて触る人が失敗しないことを優先した判断です。跡を減らしたい方は詳細モードで下げられます。</p>

<h2>対応している造形機</h2>

<p>現時点で<strong>出力ファイルを実機で確認できているのは、MUTOH（武藤工業）Value3D MagiX 系の光造形機だけ</strong>です。ネットワーク経由でプリンタを見つけ、造形ファイルを送って造形を開始するところまで対応しています。</p>

<p>正直に書いておくと、Elegoo・Anycubic・Creality といった一般的な光造形機は、それぞれ別のファイル形式を読みます。プロファイルだけ用意しても、出てきたファイルをその機械は開けません。<strong>「対応機種一覧に名前があるのに動かない」という状態を作りたくないので、確認できた機種だけを載せています。</strong></p>

<p>対応機種を広げる作業は進めています。</p>

<h2>ブラウザ版とデスクトップ版</h2>

<p>スライスまではブラウザで完結します。ただし<strong>造形機へファイルを送るところだけは、デスクトップ版が必要</strong>です。</p>

<p>技術的な理由があります。造形機は暗号化なしの通信で待ち受けているため、ブラウザは安全上の仕組みとして、https のページからそこへ接続することを禁止しています。これは設定で回避できるものではありません。造形機と同じネットワークにあるパソコンでアプリとして動かすと、この制限がなくなります。</p>
```
